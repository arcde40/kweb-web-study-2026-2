# 방명록 API 명세 (3주차 기본안)

2주차 과제를 제출했다면 자기 `spec.md`를 쓰고, 아직이라면 이 명세로 시작하세요.

## 데이터

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `id` | number | 서버가 붙이는 번호 (1부터 증가) |
| `author` | string | 작성자 이름 |
| `content` | string | 글 내용 (비어 있으면 안 됨) |

데이터는 메모리(배열)에 저장합니다. 데이터베이스는 4주차에 다룹니다.

## API

| 메서드 | 경로 | 요청 바디 | 성공 | 실패 |
| --- | --- | --- | --- | --- |
| GET | `/posts` | - | 200, 글 목록 (배열) | - |
| POST | `/posts` | `{ "author": string, "content": string }` | 201, 만든 글 | `content`가 비어 있으면 400 |
| DELETE | `/posts/:id` | - | 204 | 없는 `id`면 404 |

## 구조

- Express를 사용합니다.
- 기능 단위로 파일을 나눕니다. (예: `app.js`, `routes/posts.js`)
- 에러 응답은 `{ "error": "메시지" }` 형태의 JSON으로 보냅니다.
