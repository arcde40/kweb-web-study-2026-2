# 일기장 웹 서비스 명세

## 서비스 개요
날씨와 기분을 함께 기록해 하루를 돌아볼 수 있는 개인용 웹 일기장이다.

## 주요 기능
- 일기를 작성하고 목록과 상세 내용을 조회할 수 있다.
- 기존 일기를 수정하거나 삭제할 수 있다.
- 날짜별로 일기를 하루 한 편만 작성할 수 있다.
- 일기 내용은 필수이며, 공백을 제외한 내용이 있어야 한다.
- 일기 내용은 최대 500자로 제한한다.
- 작성 시 오늘의 날씨와 기분을 모두 입력해야 한다.
- 날씨와 기분은 정해진 선택지 없이 자유롭게 입력한다.

## 사용 및 저장 방식
- 개인용으로 제공하며 로그인이나 계정 기능은 포함하지 않는다.
- 일기 데이터는 서버 메모리에 저장한다. 서버를 재시작하면 저장된 일기는 초기화된다.
- 날짜별 작성 제한은 사용자의 브라우저 현지 날짜를 기준으로 적용한다.

## 화면 디자인
- 전체 화면은 어둡고 우중충한 폭풍우 분위기로 구성한다.
- 배경에 빗줄기와 간헐적인 번개 섬광 효과를 표시한다.
- UI에는 채도가 낮은 어두운 청회색 계열을 사용한다.
- 번개 장식을 사용하고, 사용자의 운영체제에서 동작 줄이기 설정이 활성화된 경우 애니메이션을 중지한다.

## 기술 스택
- 서버: Express.js
- 클라이언트: HTML, CSS, JavaScript
